# Phase 1 & 2 Security and Architecture Audit (`AUDIT_PHASE_1_2.md`)

**Audit Date:** 2026-11-13  
**Scope:** `/laravel-platform/` (Migrations, Models, OIDC/OAuth Services, Policy Engine, Middleware, Seeders, Routes, Blade Views, Tests)

---

## Executive Summary
Phase 1 and Phase 2 established the core 34-table MySQL schema, Eloquent UUID trait, hierarchical policy intersection logic, RS256 JWKS service, and initial seeders. However, deep source inspection identified **4 Critical** and **5 High/Medium** gaps that must be resolved before Phase 3–5 implementation.

---

## Findings & Severity Matrix

| ID | Severity | Area | Finding | Affected Files | Remediation |
|---|---|---|---|---|---|
| **AUD-01** | **Critical** | Passport & OIDC Bridge | Missing `AppServiceProvider` Passport configuration (`tokensExpireIn`, `refreshTokensExpireIn`, `tokensCan`, authorization view binding) and missing `config/auth.php` `api` Passport guard. `OidcService::issueIdToken()` is not yet connected to Passport token/authorization lifecycle, and `oauth_transactions` state (`nonce`, `code_challenge`, `amr`) is not persisted across login -> consent -> code exchange. | `app/Providers/AppServiceProvider.php`, `config/auth.php`, `app/Modules/OIDC/`, `routes/web.php`, `routes/api.php` | Add `AppServiceProvider` Passport setup, `config/auth.php`, `OAuthTransaction` persistence (`oauth_transactions` migration/model), `OAuthAuthorizationController`, and `IssueOidcIdToken` bridge + `twsd:oidc:rotate-key` Artisan command. |
| **AUD-02** | **Critical** | Missing Eloquent Models | `Application::redirectUris()` references `App\Models\OAuthRedirectUri`, `Organisation::domains()` references `App\Models\OrganisationDomain`, and `OidcController::logout()` references `App\Models\SsoSession`, none of which exist yet on disk (fatal `Class not found` on runtime). | `app/Models/Application.php`, `app/Models/Organisation.php`, `app/Http/Controllers/Oidc/OidcController.php` | Create all missing models: `OAuthRedirectUri`, `OrganisationDomain`, `OrganisationBranding`, `BrandingVersion`, `EmailConfiguration`, `OtpTransaction`, `OtpDeliveryLog`, `OtpAttempt`, `SsoSession`, `UserSession`, `LoginAttempt`, `SecurityEvent`, `AuditLog`, `ConfigurationHistory`, `ConsentRecord`. |
| **AUD-03** | **Critical** | Migration FK Consistency | `user_identities.organisation_id` (in `000001`), `user_roles.application_id` (in `000003`), and `organisation_branding.published_version_id`/`draft_version_id` (in `000002`) lack foreign key constraints because referenced tables are created in later migrations. Also `application_auth_methods.provider_code` and `organisation_auth_methods.provider_code` lack FK or composite integrity checks. | `database/migrations/2026_01_01_000001..000005` | Add a clean schema-linking migration (`2026_01_01_000007_add_cross_module_foreign_keys_and_oauth_transactions.php`) adding `oauth_transactions` and enforcing cross-table FKs cleanly without breaking rollback order. |
| **AUD-04** | **Critical** | Blade Route References | `resources/views/authentication/login.blade.php` references named routes `auth.email.password`, `auth.password.forgot`, and `auth.provider.start`, which are not yet registered in `routes/authentication.php` or `routes/web.php`. | `resources/views/authentication/login.blade.php`, `routes/web.php` | Implement `routes/authentication.php`, `routes/admin.php`, `routes/web.php`, and wire them in `bootstrap/app.php`. |
| **AUD-05** | **High** | OIDC Signing Key Hardening | `OidcService::issueIdToken()` passes `$signingKey->encrypted_private_key_pem` directly without validating the decrypted OpenSSL key resource or providing an Artisan key-rotation command (`twsd:oidc:rotate-key` referenced in `INSTALLATION.md`). | `app/Modules/OIDC/Services/OidcService.php`, `app/Console/Commands/` | Validate OpenSSL private key handle before signing, add `RotateOidcSigningKeyCommand`, and ensure `SigningKeyMetadata` never leaks PEM material in serialization. |
| **AUD-06** | **High** | Logout & Session Revocation | `OidcController::logout()` checks `oauth_redirect_uris` globally without binding to the application identified by `client_id` or `id_token_hint`, and does not revoke child `user_sessions` or Passport access/refresh tokens associated with the SSO session. | `app/Http/Controllers/Oidc/OidcController.php` | Scope `post_logout_redirect_uri` check to the resolved client application when `client_id`/`id_token_hint` is supplied, and revoke `sso_sessions` + `user_sessions` + audit log on logout. |
| **AUD-07** | **High** | Tenant Isolation Enforcement | Missing `EnsureOrganisationActive`, `ResolveOrganisation`, `RequireOrganisationPermission`, `EnforceGlobalProviderPolicy`, `EnforceOrganisationPolicy`, `EnforceApplicationPolicy`, and `AuditSensitiveAction` middleware + Eloquent Policies for `Application` and `Organisation`. | `app/Http/Middleware/`, `app/Policies/` | Implement all required middleware, policies, and `AuditService` before Phase 3 endpoints. |
| **AUD-08** | **Medium** | Wildcard Redirect URI Guard | Redirect URI exact-match validation is declared in config (`allow_wildcard_redirect_uris => false`) but not yet enforced by a dedicated validator/service class. | `app/Modules/OAuth/` | Implement `RedirectUriValidator` + `OAuthClientService` rejecting `*`, relative URIs, non-HTTPS non-localhost URIs, and fragment `#` components. |
| **AUD-09** | **Medium** | Conformance & Execution Status | Automated tests (`OidcAndPkceComplianceTest.php`, `PolicyResolutionAndTenantIsolationTest.php`) exist as valid PHPUnit classes but have **not been executed** because PHP 8.3/MySQL 8 are absent in the current sandbox container. | `DEVELOPMENT_STATUS.md`, `tests/` | Keep execution status strictly honest ("Implemented, pending PHP 8.3+ host execution") and expand tests to cover all Phase 3–5 requirements. |
